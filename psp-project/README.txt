CARPETA DEL JUEGO PSP
=====================

Coloca aquí el proyecto PSP completo:
- Makefile o makefile
- archivos .c/.h
- recursos y carpetas que utilice el juego

Después ejecuta en GitHub Actions el workflow:
"Compile PSP project with PSPDEV".

Esta carpeta solo contiene esta guía hasta que añadas los fuentes del juego.
No se incluye EBOOT.PBP de ejemplo porque no sería un binario compilado real.
